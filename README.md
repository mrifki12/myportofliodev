# Rifki Portfolio

Personal portfolio website of Muhammad Rifki — Full Stack Web Developer at PT Penta Inti Edukasi. It presents his profile, projects and experience, including pentatest.id, the Laravel-based exam platform used by 17 schools.

Live site: https://rifki.tech

## Features

- Portfolio pages for projects and experience, with a GitHub activity section
- Animated interface built with Framer Motion
- Markdown-based content rendered with react-markdown
- Contact form that sends messages via EmailJS
- Responsive design styled with Tailwind CSS

## Tech Stack

- Next.js 16, React 19, TypeScript
- Tailwind CSS 4
- Framer Motion for animations
- EmailJS for the contact form
- react-markdown and @tailwindcss/typography for Markdown content
- lucide-react and react-icons for icons

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open http://localhost:3000 in your browser.

```bash
# Production build
npm run build
npm start
```

## Project Structure

```
src/            # App source code (pages, components)
```
